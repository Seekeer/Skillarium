# Agent Skills Updater

`client/` — эталон устанавливаемой части; `server/` — управление отдельными
Git-каталогами скиллов из `server/catalogs.json`. payload скиллов здесь нет.
Редактируй клиентские скрипты только в `client/`; сервер разворачивает их в
каталоги и сохраняет манифест владения. Новые файлы шаблонов должны быть явно
добавлены в CLIENT_FILES и учтены при миграции старого манифеста.

Для добавления источника прочитай
[add-shared-skill](server/skills/add-shared-skill/SKILL.md).
Для просмотра/одобрения версий —
[check-skill-updates](server/skills/check-skill-updates/SKILL.md).
Для подключения каталога, развёртывания клиента и обслуживания —
[maintain-skill-catalogs](server/skills/maintain-skill-catalogs/SKILL.md).
Команды и границы автоматизации описаны в [README.md](README.md).

Сервер работает на i3 с Python; клиенты работают на Linux/Windows без Python.
Сохраняй чужие установки, локальные правки Git/кеша и ручные изменения
клиентских копий. Управляющие скиллы проектные: полный текст в server/skills,
а .codex/skills содержит указатели для обнаружения. Во Fleet этих скиллов нет.

Проверяй обслуживание на временных Git-каталогах с локальным bare remote и
временными HOME/XDG_CACHE_HOME. Реальные пользовательские каталоги в тестах
не используй. Проверяй владение файлами, публикацию/повтор push и сохранность
реестра при обновлении клиента. PowerShell на Linux проверяет синтаксис,
скачивание и хеши; junctions/Планировщик требуют Windows.
