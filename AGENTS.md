# Agent Skills

Этот репозиторий содержит скрипты и реестр `sources.json` версии 2.
Содержимое устанавливаемых скиллов хранится только во внешних источниках и
локальном кеше пользователя. payload и каталога `skills/` здесь нет.

Для регистрации источника прочитай
[add-shared-skill](.codex/skills/add-shared-skill/SKILL.md).
Для просмотра доступных обновлений и одобрения версии прочитай
[check-skill-updates](.codex/skills/check-skill-updates/SKILL.md).
[README.md](README.md) описывает формат реестра, ограничения и команды.

Клиенты Linux/Windows устанавливают закреплённые версии через `install.sh`
и `install.ps1`, используя общий `scripts/skills.py` (стандартная библиотека
Python). Проверку источников и публикацию новых версий выполняет только i3
через `check-updates.sh`. Флаг auto_update относится к принятию новых версий
в реестр, а не к доставке уже принятой версии на компьютеры.

Управляющие скиллы остаются проектными в `.codex/skills/`. Сохраняй чужие
установки, локальные правки и закреплённые версии при ошибках проверки.
Техническая проверка структуры/хеша не означает анализа поведения скилла.

Проверяй изменения интеграционными сценариями с локальным upstream и bare
remote, временными HOME и XDG_CACHE_HOME. Реальные пользовательские каталоги
в тестах не используй. Windows-поведение требует проверки на Windows.
