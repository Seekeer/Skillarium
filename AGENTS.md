# Agent Skills

Общие устанавливаемые скиллы находятся в `skills/<name>/SKILL.md`.
Управляющий скилл `.codex/skills/add-shared-skill/` действует только в этом
проекте и не устанавливается пользователю глобально.

При запросе добавить скилл по ссылке, файлу или архиву прочитай
[add-shared-skill](.codex/skills/add-shared-skill/SKILL.md). Для работы с
доставкой и расписанием установки используй [README.md](README.md).

Linux и Windows должны получать одинаковый набор скиллов через `install.sh`
и `install.ps1`. Сохраняй чужие установки и локальные изменения Git.
Автоматическое получение из сторонних источников и доставка из этого
репозитория — разные настройки; выбор источников хранится в `sources.json`.

Проверяй изменения синхронизации интеграционными сценариями с локальным
bare remote и временным HOME. Не используй настоящие пользовательские
каталоги скиллов в тестах. Windows-поведение проверяй на Windows; разбор
PowerShell на Linux подтверждает только синтаксис.
