# Добавить общий скилл

Прочитай README и server/README.md Skillarium. Библиотека — отдельный
репозиторий пользователя (клон обычно `~/Skillarium/library`); публикация
всегда идёт через PR с автослиянием.

Команды движка (`server/manage.py`, `install.*`) запускаются из
установленного Skillarium: `~/.local/share/skillarium/current/...`
(`%LOCALAPPDATA%\Skillarium\current\...`); библиотека берётся из конфига
Skillarium или `--repo`/`--library`. Ниже пути даны относительно движка.

## Собственная папка без внешнего источника

На любой подключённой машине: `python3 server/manage.py import-local <folder>`
(или просто положи корректную папку в `skills/<name>/` и запусти
синхронизацию клиента). Имя берётся из `name` в SKILL.md, нужен `description`.
Команда проверяет папку и Windows-пути, копирует её в `skills/<name>/` и
запускает синхронизацию клиента, которая публикует PR. `--dry-run` только
проверяет, `--no-publish` только копирует. Исходная папка сохраняется.
Запись `source.kind=local` в реестр добавит назначенный сервер при очередном
обслуживании; внешний источник по содержимому папки не угадывается.

## Внешний источник

Только на назначенной серверной машине (`python3 server/manage.py status`).

1. Определи Git URL, подпапку и полный ref (refs/heads/main или тег). Для
   одиночного SKILL.md допустим HTTPS URL. При коллекции уточни скилл только
   при неоднозначности.
2. Спроси о политике: «Применять совместимые обновления автоматически и
   спрашивать только при конфликте (auto) или подтверждать каждое обновление
   (confirm)?» Явно данный выбор не переспрашивай и не выдумывай.
3. Выполни `python3 server/manage.py register <name> --git-url <url> --path
   <subdir> --ref <full-ref> --policy auto|confirm` (для файла — `--url`).
   Команда проверяет структуру и точный SHA256 и публикует папку, базу
   `upstream/<name>/` и запись через серверный PR.
4. Проверь, что PR принят (`git log origin/main`), запись в sources.json и
   совместимость скилла с агентами/ОС. Проверка структуры не оценивает смысл
   инструкций. Остальные машины получат скилл своей синхронизацией.

Секреты храни в механизме Git пользователя. При конфликте имени согласуй
замену. Ручные изменения и чужие коммиты сохраняй; force-push не используется.
Если серверный таймер отсутствует, сообщи: политика сама расписание не создаёт.
