# Agent Skills

Общие скиллы для Codex, OpenCode и Claude Code на компьютерах одного
пользователя. У каждого компьютера своя копия этого Git-репозитория.

## Установка

Нужны Git и настроенный доступ к remote без интерактивного ввода пароля.
На Linux нужны Bash, flock и пользовательский systemd. На Windows нужны
Windows PowerShell 5.1+ и локальный диск для junctions. Администратор и
Developer Mode не требуются. Запускайте под пользователем, который работает
с агентами, из любой папки; местоположение проекта определяется скриптом.

Linux:

```bash
bash /path/to/agent-skills/install.sh
```

Windows, из PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\My\Dev\agent-skills\install.ps1
```

Установщик сразу синхронизирует репозиторий, подключает скиллы и включает
повтор раз в час. Создаются отдельные ссылки в `~/.agents/skills/<name>` и
`~/.claude/skills/<name>` (на Windows — в профиле `$HOME`). Первый каталог
используют Codex и OpenCode, второй — Claude Code. Чужие файлы и ссылки
сохраняются; конфликты отмечаются ошибкой. Повторный запуск безопасен.

На Linux таймер работает, пока активен пользовательский systemd. Работа
после выхода пользователя требует отдельно настроенного linger. На Windows
задача работает, пока пользователь вошёл в систему; пароль не сохраняется.
Выключенные компьютеры обновятся при следующем доступном запуске задачи.
WSL устанавливается отдельно через Linux-скрипт внутри WSL.

## Git remote

Приватный репозиторий: [dim/agent-skills](https://gitea.example.org/dim/agent-skills).
Для получения изменений на разных компьютерах нужен доступ к нему и
отслеживаемая ветка `main`. Клонирование на Linux:

```bash
git clone https://gitea.example.org/dim/agent-skills.git ~/Dev/agent-skills
bash ~/Dev/agent-skills/install.sh
```

На Windows:

```powershell
git clone https://gitea.example.org/dim/agent-skills.git C:\My\Dev\agent-skills
powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\My\Dev\agent-skills\install.ps1
```

Если origin ещё не задан, скрипт сообщает об этом и подключает локальные
файлы. При настроенном origin, но отсутствующей upstream-ветке, обновление
завершается ошибкой. Доступ в фоне использует обычные SSH-ключи или Git
credential manager пользователя. Секреты не хранятся в этом репозитории.

Ежечасный запуск делает `git pull --ff-only` и проверяет ссылки даже без
нового commit. Локальные изменения, detached HEAD и расхождение истории
сохраняются и требуют ручного решения. Установленные ссылки остаются рабочими
при сетевой ошибке; остальные доступные ссылки проверяются. Параллельные
запуски защищены блокировкой. Скрипты из импортируемых скиллов не выполняются.

## Добавление скиллов

Поместите скилл в `skills/<name>/SKILL.md`, вместе с его скриптами,
справочными файлами и лицензией. Сохраните и отправьте изменение в Git.
На подключённых компьютерах новая папка получит ссылки при следующей
синхронизации. Старые скиллы обновляются вместе с файлами репозитория.
Загрузка новых инструкций текущим чатом зависит от агента; новый сеанс
обеспечивает повторное обнаружение. Совместимость инструментов и инструкций
самого скилла с каждым агентом проверяется отдельно.

Для импорта по ссылке или файлу в этом проекте есть `$add-shared-skill`:
[инструкции](.codex/skills/add-shared-skill/SKILL.md). Он спрашивает, следует
ли автоматически получать новые версии из внешнего источника. Выбор и
источник сохраняются в `sources.json`. Ежечасные установщики синхронизируют
этот репозиторий, а обновление из сторонних источников выполняется отдельно
агентом по согласованному расписанию. Пока источники не добавлены, такие
автообновления не включены.

Удаление или переименование скилла оставляет старую ссылку: удалите только
соответствующую ссылку/junction вручную. Скрипт не удаляет пользовательские
данные автоматически. После переноса копии репозитория исправьте старые
ссылки и повторите установку, чтобы обновить путь в задании.

## Проверка и управление

Linux:

```bash
bash install.sh --sync-only
bash install.sh --link-only
systemctl --user list-timers agent-skills.timer
journalctl --user -u agent-skills.service -n 30
bash install.sh --uninstall
```

Windows:

```powershell
.\install.ps1 -Mode Sync
.\install.ps1 -Mode Link
Get-ScheduledTask -TaskName 'AgentSkills-Hourly-*' | Get-ScheduledTaskInfo
.\install.ps1 -Mode Uninstall
```

Удаление расписания сохраняет скиллы и ссылки. Для проверки изоляции и
синхронизации на Linux: `python3 -m unittest discover -s tests -v`.
