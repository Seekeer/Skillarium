# Добавить источник общего скилла

Работай в корне agent-skills; прочитай `README.md`. Репозиторий содержит
только скрипты и `sources.json`, а не содержимое общих скиллов. Этот
управляющий скилл остаётся проектным.

1. Определи источник. Предпочитай Git URL, путь скилла внутри репозитория и
   полный ref (`refs/heads/main` или `refs/tags/...`). Для одиночного SKILL.md
   допустим версионный HTTPS URL. Для ссылки на коллекцию уточни выбор при
   неоднозначности. Файлу/архиву нужен отдельный опубликованный источник:
   согласуй репозиторий содержимого и подготовь файлы там, а не в agent-skills.
2. Спроси: «Автоматически принимать новые версии этого источника после
   технической проверки раз в сутки на i3?» Варианты «Да» и «Нет, только
   после ручного одобрения». Учитывай явно данный выбор без повторного
   вопроса. Пока ответа нет, подготовь источник и анализ без регистрации
   с выдуманным значением auto_update.
3. Запусти `python3 scripts/skills.py register <name> --git-url <url>
   --path <subdir> --ref <full-ref> --auto-update yes|no` либо вариант `--url`.
   На Windows используй `py -3`/`python.exe`. Команда проверяет источник,
   скачивает его в локальный кеш и закрепляет revision/content_sha256.
   Секреты сохраняй в пользовательском механизме Git, не в URL реестра.
4. Проверь полученный sources.json и метаданные скилла. Совместимость его
   инструкций с Codex/OpenCode/Claude Code и ОС оцени отдельно от технической
   проверки. Одноимённую запись другого источника заменяй только по выбору
   пользователя. Существующую запись того же источника обновляй по правилам
   [check-skill-updates](../check-skill-updates/SKILL.md).
5. Просьба добавить скилл включает commit/push относящихся к регистрации
   изменений. Сохрани чужие правки; force-push не используй. Затем запусти
   `bash install.sh --link-only` или `install.ps1 -Mode Link`, проверь обе
   пользовательские ссылки. Другие клиенты получат опубликованный реестр
   по собственному ежечасному расписанию.

Проверка источников запускается скриптом на i3: расписание и команды
описаны в README. T3-задачу или запуск модели для регулярной проверки
не создавай. Если ежедневный таймер не настроен, сообщи это отдельно;
сам флаг auto_update не запускает проверку. В результате назови источник,
закреплённую версию, выбор обновления, commit и статус локальной установки.
