# Источники и их автообновление

В `sources.json` хранится объект `version: 1` и словарь `skills`. Ключ — имя
скилла. Значение содержит:

- `source`: `kind` (`git`, `url`, `file`), `url` или исходное имя файла;
  для Git также `path` внутри репозитория и отслеживаемый `ref`.
- `installed_revision`: SHA Git или хеш загруженного содержимого.
- `installed_files_sha256`: словарь относительных путей и SHA256 всех
  импортированных файлов для обнаружения локальных правок.
- `auto_update`: ответ пользователя; `true` только при постоянном источнике.
- `local_changes`: описание адаптации, если исходник доработан при импорте.

Сохраняй явное закрепление версии. URL с токенами и абсолютные локальные
пути не записывай. Хеши позволяют обнаружить правки перед заменой файлов:
при конфликте сохрани действующую версию и сообщи о ручном обновлении.

При первом согласии найди задачу проекта `Agent Skills: обновление источников`
в доступном планировщике T3. Если её нет, создай одну `schedule_task` с
`schedule: {"type":"interval","everyMs":86400000}`, привязанную к этому
проекту, без привязки к текущему чату. Запрос:

> Используй проектный скилл $add-shared-skill. Обнови из источников только
> скиллы с auto_update=true в sources.json. Сохрани локальные адаптации,
> проверь импорт, обнови версии и хеши, сделай commit/push изменений и проверь
> локальные ссылки. Остальные компьютеры обновятся ежечасными установщиками.
> Сохранённый выбор автообновления повторно не спрашивай.

При недоступном планировщике сообщи: выбор сохранён, фоновое обновление
источников пока не настроено. Поле JSON не означает работающее расписание.
Не создавай дополнительную задачу для каждого компьютера или каждого скилла.
При отказе от последнего автообновления отключи общую задачу источников;
ежечасную доставку репозитория оставь включённой.

Запланированное выполнение сначала обновляет чистую управляющую копию
репозитория. Для выбранных источников проверяет изменения, переносит полный
набор импортированных файлов, удаляет только устаревшие импортированные
файлы, обновляет реестр, делает commit/push. Новый контент проверяется как
при первом импорте; команды из него сами по себе не становятся командами
установщика. При конфликте одного скилла продолжи остальные и сообщи результат.
Не ищи собственную задачу в планировщике во время её запланированного запуска.
